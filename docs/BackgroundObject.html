Class: BackgroundObject

BackgroundObject(imagePath, x)

Represents a background object in the game world. Background objects are positioned side by side to build the scenery.

Constructor

new BackgroundObject(imagePath, x)

Creates a new background object with the given image and x position.
Parameters:
Name Type Description
imagePath string The path to the background image.
x number The horizontal position of the background object.
